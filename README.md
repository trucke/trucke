Hi 👋 My name is Kevin
======================

Code Wrangler & Software Architect
----------------------------------

10+ years taming wild bytes in software development, IT security, and automation. When not building application platforms or architecting web apps, I'm probably debugging my smart home that's suspiciously becoming self-aware.  

I turn tea (no - not coffee) into reliable code and software that actually works on Mondays. My past adventures include: 
- Creating IoT platforms (that don't spy on you... much)
- Engineering IT security software (because hackers need worthy opponents)
- Architecting scalable web applications (that actually survive Reddit hugs)
- Crafting CI/CD pipelines (so deployment day isn't also called panic day)

Passionate about innovation that matters and collaborations that don't require 47 meetings. Currently exploring AI, automation, education, and self-hosting everything because who needs the cloud when you can have your own mini data center heating your home! 🔥🖥️

* 🌍  I'm based in Klagenfurt, Austria
* ✉️  You can contact me at [kt@code.pm](mailto:kt@code.pm)
* 🧠  I'm learning Go, Elixir, Astro, Vue.js
* 🤝  I'm open to collaborating on interesting projects
